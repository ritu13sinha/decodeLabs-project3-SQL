# SQL Data Analysis Project

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Industrial Training Program.

The objective of this project was to analyze an ecommerce dataset using SQL queries and extract meaningful business insights.

## Tools Used

* MySQL Workbench
* SQL
* Microsoft Excel
* Microsoft Word

## SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* COUNT()
* SUM()
* AVG()

## Project Tasks

* Data exploration
* Data filtering
* Sorting records
* Aggregation analysis
* Revenue analysis
* Order status analysis
* Payment method analysis

## Outcome

The project successfully demonstrated how SQL can be used to extract valuable insights from raw business data and support data-driven decision making.
